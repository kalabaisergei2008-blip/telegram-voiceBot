⚙️ Настройка профиля VoiceBot

📝 Шаг 1: Как получить Notion Token?
  1. Перейдите в браузере на страницу notion.so/my-integrations.
  2. Нажмите кнопку "+ New integration".
  3. Укажите любое имя (например, VoiceBot), выберите ваш Workspace и нажмите Submit.
  4. В меню слева откройте вкладку "Secrets".
  5. Нажмите "Show", затем "Copy". Токен должен начинаться на ntn_....
  6. Важно! Откройте вашу таблицу в Notion, нажмите на три точки (...) вверху справа -> "Add connections" и выберите созданный VoiceBot.
📝 Шаг 2: Как узнать Database ID?
  1. Откройте вашу таблицу Notion как отдельную страницу (кнопка "Open as page").
  2. Посмотрите на адресную строку вашего браузера.
  3. ID — это длинный 32-значный набор символов после последнего слэша / и до знака вопроса ?.
  4. Пример ссылки:
    ...notion.so/workspace/36e607a8901d803f93f7e0c3752d3ebe?v=...
    Ваш ID: 36e607a8901d803f93f7e0c3752d3ebe.
📝 Шаг 3: Как получить Gemini API Key?
  1. Перейдите на официальный сайт разработчиков aistudio.google.com.
  2. Войдите под своим Google-аккаунтом.
  3. В верхнем левом углу нажмите на кнопку "Get API key".
  4. Нажмите синюю кнопку "Create API key", выберите проект (или создайте дефолтный) и скопируйте сгенерированный ключ. Он начинается на AIzaSy....
