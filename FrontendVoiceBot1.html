⚙️ Подключение профиля VoiceBot

Как получить Notion Token?
  1. Перейдите на notion.so/my-integrations.
  2. Нажмите "+ New integration", введите любое имя и сохраните (Submit).
  3. В меню "Secrets" нажмите "Show" -> "Copy" (токен начнется с ntn_).
  4. Важно: В Notion откройте свою базу, нажмите "..." вверху справа -> "Add connections" -> выберите вашего бота.
Как найти Database ID?
  1. Откройте вашу базу данных Notion как отдельную страницу (Open as page).
  2. Скопируйте URL из строки браузера.
  3. ID — это длинный 32-значный код после последнего слэша / и до знака ?.
Как получить Gemini API Key?
  1. Перейдите на сайт aistudio.google.com.
  2. В левом верхнем меню нажмите кнопку "Get API key".
  3. Нажмите "Create API key" и скопируйте полученную строку (начинается с AIzaSy).
