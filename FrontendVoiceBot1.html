⚙️ Подключение профиля

Как получить Notion Token?
  1. Зайдите на notion.so/my-integrations.
  2. Нажмите "+ New integration", введите имя, сохраните (Submit).
  3. Вкладка "Secrets" -> нажмите "Show" -> "Copy" (токен начнется с ntn_).
  4. Важно: В самом Notion откройте нужную базу, нажмите "..." вверху справа -> "Add connections" -> выберите созданного бота.
Как найти Database ID?
  1. Откройте вашу базу данных Notion как отдельную страницу (Open as page).
  2. Скопируйте URL из строки браузера.
  3. ID — это 32-значный набор символов после последнего слэша / и до знака ?.
Как получить Gemini API Key?
  1. Перейдите на aistudio.google.com.
  2. Нажмите "Get API key" в левом верхнем углу меню.
  3. Нажмите "Create API key" и скопируйте созданную строку (начинается с AIzaSy).
