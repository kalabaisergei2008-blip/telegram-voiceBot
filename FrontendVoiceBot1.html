Интеграция Notion

Инструкция: Токен и ID
  1. Создайте интеграцию на notion.so/my-integrations и скопируйте Secret (ntn_...).
  2. В Notion откройте базу, нажмите "..." -> "Add connections" -> выберите бота.
  3. ID базы — это 32 символа в ссылке страницы после последнего /.

Интеллект (AI)

Как получить API Key?
  1. Перейдите на aistudio.google.com.
  2. Нажмите "Get API key" -> "Create API key".
  3. Скопируйте ключ (начинается с AIzaSy).

Данные сохраняются только в вашем профиле бота
